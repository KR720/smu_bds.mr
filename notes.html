개발 기록 페이지 구축

2026년 11월 12일

기존 홈페이지를 변경하지 않고, 별도의 notes.html 페이지를 추가했습니다. ChatGPT의 지시에 따라 GitHub 파일을 수정하고 원격 저장소에 직접 커밋하는 작업 흐름을 사용합니다.

구현 방식

  • HTML, CSS, JavaScript로 구성된 정적 웹페이지
  • 별도의 로컬호스트, 개발 서버, 백엔드 없이 동작
  • 기존 홈페이지 index.html 보존
  • 개발 기록의 Markdown 파일은 notes/에 보관

남은 연결 작업

GitHub 커밋이 실제 도메인에 반영되는 배포 경로를 확인하고, Obsidian Vault와 Markdown 파일 동기화를 설정해야 합니다. 두 작업은 아직 완료된 것으로 표시하지 않습니다.

앞으로 ChatGPT 채팅에서 “개발 기록을 추가하고 GitHub에 커밋해 줘”라고 요청하면 이 페이지와 해당 기록 파일을 함께 갱신하는 방식으로 관리할 수 있습니다.
개발 규칙

AI 작업 및 웹 개발 규칙

2026년 11월 12일

웹사이트 구축

  • 웹사이트는 정적 HTML·CSS·JavaScript로 구성합니다.
  • localhost, 개발 서버 및 별도 백엔드 서버를 사용하지 않습니다.
  • 기존 홈페이지와 파일을 임의로 삭제하거나 덮어쓰지 않습니다.

GitHub 기록

  • 사용자가 ChatGPT에 요청한 변경 사항을 반영하고 커밋합니다.
  • 커밋 결과를 확인하고, 웹사이트 배포 여부는 별도로 구분해 안내합니다.
  • 인증 정보, 비밀번호, API 키 등 비밀정보는 공개 저장소에 기록하지 않습니다.

Obsidian

Markdown 노트는 추후 Obsidian Git 동기화 설정을 완료하면 Vault에서 확인할 수 있습니다. 동기화가 구성되기 전에는 자동 반영을 보장하지 않습니다.
